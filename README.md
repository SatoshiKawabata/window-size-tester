# window-size-tester

window / screen / visualViewport のサイズを表示する検証ページ。resize 等のイベントで再計測する。

公開URL: https://satoshikawabata.github.io/window-size-tester/

## クエリパラメータ

| パラメータ | 値 | meta viewport |
| --- | --- | --- |
| `viewport` | `device`（既定） | `width=device-width, initial-scale=1` |
| `viewport` | `375` | `width=375` |

例: https://satoshikawabata.github.io/window-size-tester/?viewport=375

## 公開設定

GitHub リポジトリ Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`
